AgaveDex Watch — Privacy Policy

繁體中文

Effective date: 2026-10-30
Last updated: 2026-10-31

Applies to: "AgaveDex Watch", an internal research tool operated by Agavedex (the developer of the Agavedex plant-collection app). Meta App ID 1093481716927882.

Contact: bo@forte.fyi

This policy covers AgaveDex Watch only. Agavedex mobile accounts, plant collections and public albums are covered by the Agavedex mobile app privacy policy.

1. What AgaveDex Watch is

AgaveDex Watch is a private, read-only tool. We use the Threads API to understand the public plant-app and plant-collecting community (for example, other plant-tracking apps and discussion about agave and succulents). AgaveDex Watch does not post, reply, like, follow, or send messages, and it has no public users. It is used only by the Agavedex team.

2. Data we access through the Threads API

We access only data that Meta makes available through the permissions granted to this app:

PermissionDataNotes
threads_basicBasic profile of the Threads account that authorised the app (our own account)Needed to call the API
threads_profile_discoveryPublic profile information of public Threads accounts we look up: username, display name, bio, profile link, follower count, and their public posts with any public metrics returnedPublic accounts only
threads_keyword_searchPublic Threads posts that match keywords we search (e.g. plant and app-related terms): post text, link, author username, timestamp, and any public metrics returnedPublic posts only

We do not access private accounts, direct messages, passwords, contact lists, location, or payment information. We do not use Threads data to identify people outside Threads.

3. How we use the data

  • Internal competitor analysis: tracking public updates and announcements from other plant-app accounts.
  • Internal market research: summarising public topics and common problems in the plant community so we can improve the Agavedex app.

Outputs are internal notes and summaries (for example, a weekly topic list with links to the original public posts).

We do not:

  • sell, rent, or license Threads data;
  • share it with advertisers, data brokers, or other third parties;
  • use it for advertising, profiling individuals, or eligibility decisions;
  • use it to initiate contact with the people whose posts we read;
  • use it to train machine-learning models for third parties.

4. Storage, retention and security

  • Data is stored in private files and systems that only the Agavedex team can access.
  • The access token is kept in a private environment variable and is never published.
  • We keep raw API data for no longer than 12 months from collection, then delete it. The same deadline applies to Threads data in our internal notes and summaries, including usernames, post text and links.
  • If a post or account is deleted or made private on Threads, we remove the related data, including references in our notes and summaries, when we become aware of it or at our next review.
  • We take reasonable steps to protect the data. However, no storage method is completely secure.

5. Your choices and data deletion

If your public Threads content or profile information has been collected by AgaveDex Watch and you want it deleted, see our Data Deletion Instructions or email bo@forte.fyi. Within 30 days of receiving your request, we will delete the matching data, including references in our notes and summaries, and confirm by email.

6. Changes

We may update this policy. We will change the “Last updated” date above when we do.

適用範圍： 「AgaveDex Watch」，Agavedex（Agavedex 植物收藏 app 開發者）營運嘅內部研究工具。Meta App ID 1093481716927882。

聯絡： bo@forte.fyi

本政策只適用於 AgaveDex Watch。手機應用程式的帳戶、植物收藏及公開相簿受《Agavedex 手機應用程式私隱政策》涵蓋。

1. 用途簡介

AgaveDex Watch 係一個私人、只讀嘅工具。我哋透過 Threads API 了解公開嘅植物 app 同植物收藏社群（例如其他植物記錄 app，同埋龍舌蘭、多肉植物嘅討論）。本工具唔會發文、回覆、讚好、追蹤或者發訊息，亦冇公開用戶，只供 Agavedex 團隊內部使用。

2. 透過 Threads API 存取嘅資料

  • threads_basic：授權本 app 嘅 Threads 帳號（即我哋自己嘅帳號）嘅基本資料。
  • threads_profile_discovery：我哋查詢嘅公開帳號嘅公開資料，包括用戶名、顯示名稱、簡介、個人檔案連結、粉絲數，同埋佢哋嘅公開帖文同 API 提供嘅公開數據。
  • threads_keyword_search：符合關鍵字嘅公開帖文，包括內文、連結、作者用戶名、時間，同埋 API 提供嘅公開數據。

我哋唔會存取私人帳號、私訊、密碼、聯絡人、位置或者付款資料。我們不會使用 Threads 資料識別用戶在 Threads 以外的身分。

3. 資料用途

只會用嚟做內部競爭對手分析同市場研究，例如整理公開話題、社群常見問題，用嚟改善 Agavedex app。我哋唔會出售、出租或者分享資料畀第三方，唔會用嚟賣廣告或者分析個人，亦唔會用嚟主動聯絡帖文作者。亦不會向他人授權使用 Threads 資料，或用這些資料評定個人資格、為第三方訓練機器學習模型。

4. 儲存、保留期同保安

資料存放喺只有 Agavedex 團隊先存取到嘅私人檔案同系統。存取 token 放喺私人環境變數，從來唔會公開。原始 API 資料自收集日起最多保留 12 個月，之後會刪除。內部筆記及摘要中的 Threads 資料，包括用戶名稱、帖文內容及連結，均受同一期限約束。如果帖文或帳號在 Threads 上被刪除或設為私人，我們會在得悉後或下次檢查時移除相關資料，包括筆記及摘要中的引用。我們會採取合理措施保護資料，但任何儲存方式都無法保證絕對安全。

5. 刪除資料

如想刪除你的資料，請參閱資料刪除說明，或電郵至 bo@forte.fyi。我們會在收到申請後 30 日內刪除相關資料，包括筆記及摘要中的引用，並以電郵確認。

6. 政策更新

政策如有更新，我們會更改上方的「最後更新」日期。
